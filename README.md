# korean-public-workbench
한국 법률·공공 9개 분야 공식 자료 검색, 준비 체크리스트, 개인정보·지급명령·조사 기록 초안 생성 도구

> 이 도구가 만드는 문서는 **초안**이며 법률 자문이 아닙니다. 제출 전 공식 기관 안내를 확인하고,
> 필요하면 대한법률구조공단(☎ 132) 등에서 상담받으세요.

## 기능
### 1. 분야별 공식 자료·체크리스트 (9개 분야)
법령·판례 / 소송·지급명령 / 개인정보 / 행정·민원 / 정보공개 / 노동 / 소비자 / 세금 / 법률상담·구조

- 분야마다 공식 기관 링크(국가법령정보센터, 전자소송, 개인정보보호위원회, 정부24, 정보공개포털, 고용노동부, 한국소비자원, 홈택스, 대한법률구조공단 등)
- 준비 체크리스트와 진행 표시, 검색(예: "임금" → 노동)

### 2. 문서 초안 3종
| 문서 | 근거 | 내용 |
|---|---|---|
| 개인정보 열람·정정·삭제·처리정지 요구서 | 개인정보 보호법 제35~37조 | 선택한 요구만 번호를 매겨 작성 |
| 지급명령 신청서 | 민사소송법 독촉절차 | 청구취지(금액 한글 병기, 선택 시 지연손해금), 청구원인, 소명자료 |
| 사실 조사·면담 기록 | — | 일시·참석자·진술 요지·자료·추가 확인 사항, 확인 서명란 |

- 필수 항목 검사, 빈칸은 `[항목명]`으로 표시
- 결과 창에서 바로 고친 뒤 복사·.txt 저장·인쇄(인쇄 시 초안만 출력)

### 개인정보 보호
- 서버 전송 없음. 체크 상태와 입력값은 이 브라우저의 `localStorage`에만 저장됩니다
  (공용 PC라면 사용 후 **입력 지우기**를 누르세요).
- **주민등록번호로 보이는 값은 초안·저장 파일·브라우저 저장소 모두에서 자동으로 가립니다** (`900101-1******`).

## 실행
`index.html`을 브라우저로 열면 됩니다. 설치·서버가 필요 없습니다.

## 유의 사항
- 기관 링크는 각 기관 첫 화면입니다. 검색 주소 형식은 자주 바뀌어 넣지 않았습니다.
- 지급명령의 관할 법원·인지대·송달료·이율은 사건마다 다르므로 전자소송 화면이나 법원 안내에서 확인하세요.
- 상담 전화번호는 대표번호이며 운영 시간은 기관 사이트에서 확인하세요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `data.js` | 9개 분야 기관 링크·체크리스트 |
| `drafts.js` | 초안 템플릿, 필수 항목 검사, 주민번호 가림, 금액 한글 표기 (UI 없음) |
| `drafts.test.js` | 단위 테스트 — `node --test` |

## 검증
- 단위 테스트 9개 통과 (Node 22): 링크 도메인, 주민번호 감지·가림, 금액 한글 표기, 필수 항목, 템플릿 3종 출력
- Chromium 자동 점검 15항목: 검색, 체크 유지, 누락 오류, 지급명령 생성, 입력 자동 보관, 주민번호 가림(초안·저장소), 복사, 저장, 인쇄 화면, 모바일 폭, 콘솔 오류 없음
